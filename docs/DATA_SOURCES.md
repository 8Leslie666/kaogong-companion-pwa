## 导入处理

1. 校验 A–D 选项与答案范围。
2. 用稳定来源 ID、题干指纹去重。
3. 过滤乱码、空题干、缺选项和超长材料。
4. 映射到六个行测模块，并保留题源、链接和许可。
5. 缺少原始解析时保留“解析草稿”标记语义，进入后续人工复核队列。

## 历年真题流水线

- `scripts/fetch-exam-paper-catalog.mjs`：抓取国考和各省目录，标准化年份、地区、卷型与回忆版标记。
- `scripts/fetch-exam-paper-pilots.mjs`：解析试卷 HTML 与答案页，按题号关联答案，缓存题图，输出带内容哈希的稳定 ID。
- `data/review-packs/*.json`：保存每套卷的题数、答案覆盖、跳过项、图片失败和模块分布，供发布前复核。
- 当前两套卷答案覆盖均为 100%，图片下载失败为 0；逐题解析仍为草稿状态。

开放题源带 NC 或混合来源条款，当前适用于自用原型。商业发布前按题包单独进行版权复核，并替换相应内容。
